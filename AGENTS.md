# Agents

## Projet

Refonte du site internet de l'association de chorale **Eau Vive**.

- **Rôle du développeur** : créer les pages et le design.
- **Contenu** : à la charge des bénévoles de l'association (pas du développeur).
- **Design** : créé avec [MagicPath](https://magicpath.ai). Le skill MagicPath est installé (`.agents/skills/magicpath/`) — l'utiliser pour exporter, adapter ou intégrer les composants du design.

## Skills

This project uses the Payload CMS skill at `.agents/skills/payload/`.
Start with `.agents/skills/payload/SKILL.md` for a quick reference, then see `.agents/skills/payload/reference/` for detailed docs.

## Commandes

Les commandes terminal sont exécutées par l'utilisateur, pas par l'agent. Propose les commandes à lancer sans demander d'approbation au préalable.
